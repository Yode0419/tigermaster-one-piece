# Design Ops Index

## 存在目的

隨著知識庫裡的設計工作不再只靠人類，也開始有 AI（各 skill）參與執行，design-ops 把「設計團隊自己怎麼運作」的知識規格化保存下來，讓不論是人類或 AI 在進行設計相關工作時，都有穩定、一致、可依循的基礎，而不是每次重新摸索或憑記憶行事。目標是讓這個知識庫裡的設計工作更有效率、更能穩定營運。

## 範圍

跟 `docs/wiki`（產品知識）、`docs/design-system`（UI 元件規格）不同，design-ops 管理的是設計團隊自己的工作方式：檔案怎麼組織、流程怎麼跑、跟工程怎麼交接、AI 怎麼參與設計。

## 使用方式

- **人類**：建立或稽核 Figma 檔案、新協作者熟悉團隊運作方式時查閱。
- **AI**：未來的 skill 讀取這裡的規格，依循標準自動執行設計相關操作（比照現在 sanji 讀取 design-system 的方式）。
