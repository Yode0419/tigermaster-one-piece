# 註冊與登入流程

## 概述

說明客戶與師傅在 App 以手機號註冊或登入的現況。師傅與客戶使用同一個註冊流程，經[招募流程](../operations/technician-onboarding.md)後，由客服在後台把帳號角色由客戶改為師傅，下次登入即進入師傅端介面。

---

## 流程步驟

1. **輸入手機號**
   系統先查這支手機號的帳號狀態。

2. **依帳號狀態分流**

   | 帳號狀態 | 接下來 |
   |---|---|
   | 正常 | 輸入密碼登入 |
   | 停權 | 畫面變成空白，沒有任何提示 |
   | 沒有帳號 | 進入建立帳號頁（見下方） |
   | 需重設密碼（後台代建的帳號） | 進入「重新設定密碼」頁：輸入新密碼兩次（6 到 18 位英數字），設完即可登入 |

3. **簡訊驗證**
   目前關閉，填手機號就直接通過，沒有驗證手機是否為本人的機制。

## 建立帳號頁

| 區塊 | 欄位 | 說明 |
|---|---|---|
| 基本資料 | 姓名 | 必填 |
| | 手機號碼 | 自動帶入，不能修改 |
| | 電子信箱 | 必填，格式需正確。提示文字：「務必填寫正確，電子發票及忘記密碼傳送用」 |
| 密碼設定 | 密碼、再次輸入密碼 | 6 到 18 位英數半形字元 |
| 得知渠道 | 請問您是從哪得知「師虎來了」？ | 必填，下拉選單（推廣人員、廣播電台、Facebook、股感／房感、名人推薦、新聞媒體、Podcast、親友介紹、Google 搜尋、YouTube、電視廣告、LINE 廣告、其他）。選廣播電台、名人推薦、新聞媒體、Podcast、其他時，需再補填節目、人名、媒體名稱等 |

頁面底部寫「註冊即表示您已閱讀並同意隱私權使用政策及服務條款」，兩者皆可點開閱讀。按「下一步」後完成註冊。

## 忘記密碼

1. 在密碼輸入頁點選「忘記密碼?」。
2. 輸入註冊時填寫的電子信箱，按「下一步」。
3. 畫面顯示「認證信已寄至您的信箱」，並提示連結 30 分鐘內有效。
4. 客戶到信箱點擊信中的連結，開啟官網的重設密碼頁，設定新密碼。
5. 之後用新密碼登入。

忘記密碼只能透過註冊的電子信箱，所以建立帳號時的電子信箱需填寫正確。

## 換手機登入

目前沒有額外驗證步驟，在新手機輸入手機號與密碼即可登入。

## 後台代建帳號

客服等管理員角色可在後台以手機號、姓名、Email 代客建立帳號，狀態為「需重設密碼」，並可指定角色（客戶、企業客戶等）。
