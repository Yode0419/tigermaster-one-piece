# 訂單旗標：不支付給師傅車馬費 — 決策摘要

_整理日期：2026-08-17 ｜ 產品知識文件：[師傅收款與結算機制 § 師傅車馬費收入](../../../wiki/business/master-payout.md)_

## 最終做法

後台訂單詳情頁新增「不支付給師傅車馬費」旗標，超級管理員可一鍵取消或恢復訂單狀態 30–45 終止時本應產生的 $200 師傅車馬費。系統依「有無既有車馬費收入記錄」與「訂單是否已終止」自動判斷該建立、歸零或恢復收入記錄，並在每次造成金額異動的操作時，於師傅收入記錄的註記欄位追加系統紀錄。功能已於 2026-06-01 上線，取代原本需跨頁至師傅詳情頁手動改金額、自行輸入註記的做法。

## 關鍵決策

| 決策 | 為什麼這樣決定 | 出處 |
|---|---|---|
| 旗標的操作與儲存只限**超級管理員**，其他後台角色僅可檢視、無法操作；且旗標不依訂單狀態動態 disabled | 操作者限定超級管理員，本身熟悉業務情境，不適用的情境下操作也無副作用；因此不需要再依訂單狀態額外做 disabled 判斷，省去這部分的開發與維護成本 | [no-pay-dispatch-fee.md](no-pay-dispatch-fee.md) |
| 儲存旗標時以「有無車馬費收入記錄」為主要判斷條件，而非查詢場勘狀態或報價單 | 師傅收入表單一查詢即可隱含多個條件，減少跨資料表查詢複雜度 | [no-pay-dispatch-fee.md](no-pay-dispatch-fee.md) |
| 系統註記只在金額實際變動時才寫入 | 註記目的是記錄金額異動，避免旗標重複儲存但金額未變動時產生重複記錄 | [no-pay-dispatch-fee.md](no-pay-dispatch-fee.md) |
| 取消旗標時固定恢復 $200 | 此旗標主要使用情境即為狀態 30–45 取消訂單，依制度車馬費本為 $200；極端情況（如客戶已同意報價才手動關閉訂單）不在此邏輯處理範圍，由管理員事後手動修正 | [no-pay-dispatch-fee.md](no-pay-dispatch-fee.md) |

## 曾考慮但未採用

| 方案 | 為何放棄 |
|---|---|
| 根據訂單狀態動態 disabled 旗標 | 增加開發與維護成本；操作權限本身已限定超級管理員，不需要系統再額外防呆 |

## 設計與實作的落差

無。2026-06-01 上線後實測確認：旗標勾選/取消勾選與師傅收入連動正常、車馬費產生時機正常、旗標不影響客戶端對報價單的操作功能，皆與設計文件一致（含系統註記格式、$200 固定恢復金額）。
