# SCRUM 優先順序評估草稿

範圍：SCRUM-19~70（跳過 33、66）。排除 SCRUM-34（使用者自行處理）、SCRUM-67（工程技術子任務，非 PO 視角，不適用此框架）、以及 7 張 bug 類票（另見下方「缺陷」區塊，用 defect-severity.md 判斷，不套用下面的分數）。

評分方式見 [priority-criteria.md](priority-criteria.md)：A 使用者體感／B 內部人力成本／C 產品策略相關性／D 風險降低價值，各 高=3／中=2／低=1，四軸加總 ≥10 High、7~9 Medium、≤6 Low。

「落差」欄：✓ 算出來跟 Jira 現況一致；↑ 建議調升；↓ 建議調降。這是公式算出來的參考值，不是最終定案，你可以直接改。
