# B2B2C 串接專案：總覽

## 背景

消費者在合作企業的 App 或網頁下單，訂單透過標準收單 API 直接進入師虎來了，走既有媒合。媒合成功後，消費者下載師虎 App、用同一支手機登入，就能看到原訂單並付款，不用重新下單。

師虎自己的網頁下單（師虎 Web）和企業串接是同一件事：兩者共用同一套收單 API，用訂單編號前綴區分來源（例如智生活 ROZH、師虎 Web ROWE）。第一家合作企業是智生活。

來源：[董事長 10/07 簡報](師虎來了_B2B2C.WEB串接方案_1014pdf.pdf)、[10/07 會議逐字稿](2026-10-07討論企業串接逐字稿.txt)。前身構想見 [客戶端網頁版下單構想](web-ordering-idea.md)。

## 第一版範圍

- **收單**：合作企業送資料過來，有帳號就直接成立訂單，沒有就預建帳號再成立訂單；師虎 Web 下單
- **找得到師傅**：消費者沒下載 App 也能和師傅溝通，方向是用專屬連結進入的網頁訂單頁（狀態、聊天）
- **付款**：以 App 內付款為主，網頁訂單頁引導到 App
- **後台**：訂單來源、外部訂單編號、會員狀態

## 限制

- 第一版不改 App 程式碼（師虎 Web 屬於官網，不受此限）
- 簡訊驗證目前關閉，公司也沒有發通知簡訊；我們這邊的通知只用 Email 與網頁訂單頁
- App 註冊現況：填手機號就能直接設定密碼
