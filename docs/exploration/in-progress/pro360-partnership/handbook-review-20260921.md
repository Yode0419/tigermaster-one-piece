## 二、回報表更新對照（建議）

以 MVP 案件進度回報表現有欄位與選項為基礎。

| 手冊節點 | 回報表要填 |
|---|---|
| 新案件與每次聯繫 | 案源提供時間、案件編號、案件分類、描述需求、地區、聯繫人、聯繫時間（備註記第幾次） |
| 確認需求到勘場安排中 | 訂單狀態：已聯繫媒合中 |
| 已預約勘場 | 訂單狀態：媒合成功。勘場時間、施工師傅 |
| 案件中止（24 小時無回應） | 訂單狀態：聯繫不上（空號選空號）。備註：24小時無回應，已釋回 |
| 釋回（找不到師傅、只問價、師傅不報價） | 訂單狀態：媒合失敗。備註記原因 |
| 報價已送達到最後確認 | 報價日期（送達日）、報價單金額。是否成交：7天考慮中 |
| 報價已接受 | 是否成交：是 |
| 拒絕、再看看、選其他廠商 | 是否成交：否。未成交原因：暫緩動工、已沒需求、報價太高、沒預算、不滿意師傅 |
| 交接後 | 預計完工日、驗收日、完工後狀態、保固完結日 |

現有選項只有一處不夠：「未成交原因」缺「已選擇其他廠商」，建議新增這一項。
